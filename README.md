# Storm Royale

Original browser 3D action game. **Not Fortnite.**

You drop onto a themed island with 11 allied fighters, loot, build, and team up against a giant stag in the center. The purple ring does not shrink. After 12 seconds the floor is lava until **every NPC is gone** (all 11 fighters and the Stag). Stepping outside the ring is instant death. Killing the Stag does **not** end the match — it only ends if you go down.

## Quick start

Need **Node.js 18+**.

```bash
npm install
npm run dev
```

Open the Vite URL (usually `http://localhost:5173`), click **Play**, click the game to lock the mouse.

| Input | Action |
| --- | --- |
| WASD / arrows | Move |
| Mouse | Look |
| Space | Jump (again in air = double jump) |
| Y | Stomp (in air) |
| 1 2 3 4 | Pistol / rifle / shotgun / sword |
| G or left click | Shoot / slash |
| E | Axe (chop trees) |
| R | Open chest |
| Q F C + right click | Wall / floor / ramp |
| H | Pause |
| T | Skill tree |

Progress (wins, XP, skill unlocks) saves in the browser.
